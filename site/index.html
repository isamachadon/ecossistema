    Árvore genealógica

    Cada linha é uma espécie, do dia em que surgiu até hoje (ou até sumir). Os galhos mostram quem descende de quem. Cinza com † = extinta. Clique num nome pra ver a ficha.

    Como batizar uma espécie

    1. Escolha uma espécie sem nome e anote o número dela (ex: nº 12).
    2. Abra o arquivo site/nomes.json no Bloco de Notas.
    3. Escreva o número e o nome entre aspas, separando as linhas com vírgula: 
      {
  "3": "Lesmão Guloso",
  "12": "Dona Pantufa"
}
    4. Salve e recarregue esta página (F5). Pronto, nome oficial!

    Dica: a última linha não leva vírgula. Se algo der errado, este diário avisa lá no topo.
